SHOCKSCOPE | BUILD 0.5

INSTALL: Stop Streamlit (Ctrl+C). Extract this ZIP. Copy app.py, the modules folder, test_company_math.py and this README into the existing SHOCKSCOPE folder (merge modules; replace app.py and shock_simulator.py). Do not delete any CSV or previous module. No new dependencies. From the existing environment, run:
python -m streamlit run app.py

Select 05 Company Calculator & Reports. All company inputs are in millions of the selected local currency. The event shocks and company profiles are fictional examples, not company or industry statistics. The model assumes fixed output and sales volumes. It separates price and FX effects, using the post-price-shock cost for the FX effect on the unhedged USD share. Positive net additional costs can be recovered through additional revenue; cost savings are retained. EBITDA is revenue minus cash operating costs (including COGS). Do not include depreciation, amortization, interest or taxes in cost categories. No demand, working capital or liquidity forecast. Report is local rule-based text, not a generative AI service. Event references support historical context only.
